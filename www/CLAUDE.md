# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

`www` is the public marketing site for Pherus, serving the bare apex `pherus.org`: real content now (Home, About), but still no auth, no data fetching, no `domains/`, no `QueryClient` — every page is static and English-only. `accounts` (`account.pherus.org`) and `infra` (`infra.pherus.org`) carry the actual product. See the monorepo root `CLAUDE.md` for the `infra`/`accounts`/`www` split.

Long-form prose (About's body copy) lives in `src/content/*.md`, loaded via `src/content/index.ts` (`getContent(slug)`, a `import.meta.glob(..., { query: "?raw" })` lookup) and rendered with `@tanstack/markdown`'s `<Markdown>` (from `@tanstack/markdown/react`). Short structured strings (nav labels, the founder's name/title, division names/descriptions) stay as plain TS constants — `@tanstack/markdown` is for genuinely long-form flowing prose, not one-line UI strings; don't route form labels or nav text through it. Division data lives in `src/data/divisions.tsx` (ten entries: name, dev-status, description, an inline SVG accent), rendered through `src/components/division-mark.tsx` (the shared dark-square + light-L mark every division icon is built from). `src/components/header.tsx`/`footer.tsx` are shared site chrome, mounted once in `__root.tsx` around `<Outlet />` so every route gets them automatically.

This app shares `@infra/ui`'s actual design tokens and components (`Button`, `Badge`, `Avatar`, `buttonVariants`, etc.) — it does not carry its own color palette or font stack. A link styled as a button uses TanStack Router's own `<Link>` with `buttonVariants({ variant, size })` applied as `className`, not `<Button render={...}>` (react-aria-components' `render` prop wants a render function, not a bare element) and not `LinkButton` (that renders a plain `<a>`, losing TanStack Router's client-side navigation).

Only `/` and `/about` are real routes so far. The header/footer reference a few more (Divisions, Open Knowledge, Investors, Contact, Legal) as plain non-interactive text for now, not dead links — wire them up as real `<Link>`s once those pages exist.

Package manager: **bun** (`bun.lock` is the lockfile, gitignored, autogenerated by `bun install`, never committed).

## Commands

```bash
bun install       # install dependencies
bun run dev       # start dev server on port 3002
bun run build     # production build
bun run typecheck # tsc --noEmit
bun run deploy    # wrangler deploy
```

## Architecture

Same 4-file TanStack Start convention as `infra`/`accounts` (`src/start.ts`, `src/server.ts`, `src/router.tsx`, `src/routes/__root.tsx`), stripped of everything session/query-client related since this app has no state to bootstrap. `src/routes/index.tsx` is the entire app.

Don't add `better-auth`, `@tanstack/react-query`, or a `domains/` folder here — if a feature needs any of those, it belongs in `accounts`, not `www`.
