# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

`www` is the minimal public marketing site for Pherus, serving the bare apex `pherus.org`. It's a single placeholder page (wordmark, tagline, a link out to `accounts` for sign-in) and nothing else — no auth, no data fetching, no `domains/`, no `QueryClient`. Real marketing content is a future task; this app exists only to occupy the `pherus.org` route while `accounts` (`account.pherus.org`) and `infra` (`infra.pherus.org`) carry the actual product. See the monorepo root `CLAUDE.md` for the `infra`/`accounts`/`www` split.

Package manager: **bun** (`bun.lock` is the lockfile, gitignored, autogenerated by `bun install`, never committed).

## Commands

```bash
bun install       # install dependencies
bun run dev       # start dev server on port 3002
bun run build     # production build
bun run typecheck # tsc --noEmit
bun run deploy    # wrangler deploy
```

## Architecture

Same 4-file TanStack Start convention as `infra`/`accounts` (`src/start.ts`, `src/server.ts`, `src/router.tsx`, `src/routes/__root.tsx`), stripped of everything session/query-client related since this app has no state to bootstrap. `src/routes/index.tsx` is the entire app.

Don't add `better-auth`, `@tanstack/react-query`, or a `domains/` folder here — if a feature needs any of those, it belongs in `accounts`, not `www`.
